# 公众号发布配置

## 适用对象

服务号 / 认证订阅号 / 个人订阅号都可用。个人订阅号仅支持「推到草稿箱」（公众号 App 里手动确认发布）。

## 步骤

### 1. 准备公众号凭证
登录 [公众平台](https://mp.weixin.qq.com/) → 左下角「设置与开发」→「基本配置」：
- 拿到 **AppID** 和 **AppSecret**
- 把 AI Radar 服务器 IP 加进 **IP 白名单**（否则调用 API 会被拒）

### 2. 上传素材（缩略图）
公众平台 → 素材管理 → 上传 1 张 16:9 封面图 → 复制 `media_id`

### 3. 配置 AI Radar
两种方式：

**A. 环境变量（推荐）**
管理员在 Coolify 里加：
```
WECHAT_APP_ID=wx...
WECHAT_APP_SECRET=...
WECHAT_AUTHOR=你的笔名
WECHAT_THUMB_MEDIA_ID=...
```

**B. 通过控制台填写**
打开 AI Radar → 右下角 ⚙️ 控制台 → 输入 CONSOLE_PASSWORD → 在「微信公众号」面板填入。

### 4. 测试连接
打开「内容生产线」→ 任选一篇已 ready 的文章 → 点「发布预览」（dry_run）→ 看到 `success: true` 即配置正确。

### 5. 正式发布
点「发布」按钮 → 文章推到草稿箱 → 公众号 App「素材库」里找到 → 确认排版 → 群发。

## 常见报错

- `40164` IP 不在白名单 → 把服务器出口 IP 加进公众平台白名单
- `40001` 凭证错误 → 检查 AppID/Secret 是否填对
- `40004` 不合法的媒体文件 → 缩略图 media_id 过期，重新上传
- `45009` 接口调用超过限制 → 公众号 API 有日配额，明天再试

## 安全提醒

- AppSecret 在 Coolify 环境变量里加密存储，不写到代码仓库
- AI Radar 容器只能用这个 AppSecret，不会泄露给前端用户
- 推荐启用公众号的「IP 白名单」+「消息加解密」

## 自动化建议

把 AI Radar 跟你的发布节奏对齐：
- 每天早上 9 点系统自动跑选题分析
- 上午 10:30 你点「批量生成文章」
- 中午 12 点审稿结果出来，看 1-2 篇满意的
- 下午 2 点点「批量发布到草稿箱」
- 下午 3 点公众号 App 排版定时发布晚上 7 点

整个流程一天投入 30 分钟以内。
