# 隐私政策

> 最后更新：2026-05-12
> 本政策为模板，实际对外发布前应由法务审核。

## 我们是谁

「AI Radar」（以下简称「本服务」）是一套面向内容创作者的 AI 内容生产工作台，托管在 `content.orbitlogic.dev` 等域名。

## 我们收集什么

### 1. 帐号信息
- 登录用户名 / 加密后的密码哈希
- 浏览器 User-Agent、登录 IP、登录时间

### 2. 你输入的业务数据
- 选题、文章草稿、审稿意见
- 你在控制台填写的第三方平台凭证（如微信公众号 AppSecret、各 LLM API key）

### 3. 系统自动产生的数据
- API 调用记录、错误日志（用于运维诊断）
- 审计日志（谁、何时、对哪条记录做了什么）

## 我们不收集什么

- 你的微信 / 银行 / 身份证等高度敏感信息（请勿在本服务中输入这类内容）
- 你浏览本服务之外的第三方网站的行为
- 你的麦克风、摄像头、地理位置

## 我们如何使用这些数据

- **业务运行**：让 AI 工作台能跑起来
- **运维诊断**：服务异常时定位问题
- **审计追溯**：满足合规要求和安全审查
- **服务改进**：聚合统计（匿名）分析使用习惯，改进产品

我们**不会**将你的内容用于训练任何 AI 模型。

## 数据存储

- 数据存储在中国大陆 / 中国香港 / 美国等地，具体位置取决于你购买的版本
- 数据库每日备份，保留 14 天（私有部署版可自定义保留策略）
- 静态磁盘加密（磁盘层 LUKS / FileVault）

## 第三方数据流向

为提供 AI 能力，你的「选题 / 上下文」会被发送到下列任意一个 LLM 提供商（取决于你配置的 API key）：
- DeepSeek（中国）
- Anthropic Claude（美国，可通过 TokenKey 中转）
- Google Gemini（美国）
- OpenAI（美国）
- AIRouter（自托管中转）

我们不会向其他第三方分享你的数据。

## 你的权利

- **访问**：通过 `/api/projects`、`/api/articles` 等接口可随时下载你的内容
- **更正 / 删除**：登录后直接编辑或删除
- **导出**：联系管理员获取 JSON / Markdown 全量导出
- **撤销授权**：通过控制台清空 API key，停止使用第三方 LLM

## Cookie

- 我们仅使用 HTTP Basic Auth，**不下发任何持久 Cookie**
- 浏览器会缓存认证凭证直到关闭窗口

本政策更新时会在登录页提示。重大变更（如新增第三方数据接收方）会单独邮件通知。
