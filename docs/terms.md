## 1. 接受条款

使用本服务（AI Radar，下称「本服务」），即表示你同意本条款。不同意请停止使用。

## 2. 帐号与责任

- 你需要自行保管登录凭证，由此产生的所有行为视为你本人操作
- 帐号被盗用、密码泄露应立即通知运营
- 不得将帐号转借他人或在多人间共享

## 3. 你可以做什么

- 使用本服务生成、编辑、发布属于你的内容
- 下载、导出你产生的所有数据
- 接入你自己的 LLM API key（DeepSeek / Claude / Gemini / OpenAI 等）

## 4. 你不可以做什么

- 上传 / 生成违反《网络安全法》《个人信息保护法》《互联网信息服务管理办法》等中国法律法规的内容
- 滥用 API 进行高频刷接口、爬取他人数据、垃圾发布
- 反向工程、解密、再分发本服务的源代码
- 利用本服务做任何危害国家安全、社会稳定、他人合法权益的行为

如违反，运营有权立即终止服务，且保留追究法律责任的权利。

第三方服务的故障 / 限额 / 价格变化不属于本服务可控范围。
