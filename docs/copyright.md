## 二、AI 生成内容的版权

### 1. 归属
**AI Radar 生成的所有内容（文章草稿、摘要、视频脚本等），版权归你（产出者）**。本服务不主张任何版权。

### 2. 风险提醒
AI 生成内容可能存在以下风险，需你自行审校：

| 风险 | 建议做法 |
|------|----------|
| **事实错误**（幻觉） | 关键事实人工核对原始来源 |
| **观点抄袭** | 借鉴他人观点须注明出处 |
| **生硬翻译 / AI 味** | 用「人格化润色」功能改写，发布前再读一遍 |
| **平台合规** | 公众号 / 头条 / 抖音对 AI 生成内容有不同标注要求 |

### 3. AI 内容标注（建议）
- **微信公众号**：文末注明「本文由 AI 辅助生成」即可
- **小红书 / 抖音**：发布时勾选「AI 生成内容」标签
- **学术 / 新闻媒体**：建议人工改写到不可识别为 AI 生成的程度

## 三、第三方素材

如果你的文章引用了：

- **图片** → 用免费授权图库（Unsplash / Pexels / 阿里图标库），或自己拍，避免百度图片直接下载
- **视频片段** → 仅用 Creative Commons 授权或自制
- **字体** → 用开源字体（思源 / 鸿蒙），商用字体需购买授权
- **音乐** → 用版权免费 BGM 库（YouTube Audio Library / Pixabay / 站酷海洛）

## 四、敏感话题红线

以下内容禁止生成 / 发布：

- 国家政治、领导人评论、敏感历史事件
- 涉黄、涉赌、涉毒、暴力、恐怖主义
- 散布谣言、虚假信息
- 侵犯个人隐私（人肉、未授权曝光）
- 医疗、金融、法律的专业建议（除非你本人是持证从业者）

## 五、平台合规

不同平台对内容有不同规则：

- **微信公众号**：原创声明、广告标注、引用规范
- **头条**：禁止重复发布同一文章到多个帐号
- **小红书**：AI 生成内容须标注、医疗 / 金融 / 教育需资质
- **B 站**：标注「AI 创作」标签、原创视频可申请创作激励

发布前请熟悉对应平台规则。AI Radar 不保证所有生成内容自动符合平台规则。
