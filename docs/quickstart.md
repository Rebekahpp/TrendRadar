# AI Radar — 快速开始

> AI 内容生产工作台：从热点监控到一键发布的全流程自动化。

## 30 秒了解能做什么

1. **热点监控** — 24 小时不间断抓 36kr / Hacker News / TechCrunch / OpenAI Blog / 微博 / 知乎等 14+ 来源
2. **AI 选题** — 多模型协同推荐高价值 AI 话题
3. **深度分析** — 4 个 LLM 同时分析同一选题，聚合多视角洞察
4. **自动写稿** — Claude Opus 主笔 + DeepSeek/Gemini 兜底
5. **AI 审稿** — 6 维评分（事实性、深度、可读性、原创性、结构、价值密度）+ 修订建议
6. **一键发布** — 公众号草稿箱 + 飞书通知

## 第一次使用

### 1. 登录
首页会弹出浏览器 Basic Auth 弹窗。输入管理员发给你的用户名 + 密码。

### 2. 配置 API Key
点击右下角「⚙️ 控制台」→ 输入 console 密码 → 填入你的 API key：
- `DEEPSEEK_API_KEY` — 必填（最便宜，做摘要 / 翻译 / 兜底）
- `GEMINI_API_KEY` — 推荐（Flash 模型免费额度大，做次选）
- `ANTHROPIC_API_KEY` 或 `TOKENKEY_API_KEY` — 推荐（Opus 写稿质量最好）
- `OPENAI_API_KEY` — 可选

> 💡 也可以让管理员把 key 通过环境变量配在服务器上，你就不用自己管。

### 3. 浏览今日热点
左侧导航 →「概览」。系统已经自动跑了一轮扫描，你能直接看到：
- **AI 精选** — 当天最值得做的选题（带 AI 生成的 1-3 句摘要）
- **热榜聚合** — 各平台 Top 内容
- **推荐选题** — 系统自动挖出的高价值话题

### 4. 启动一次分析
任何一条 AI 精选 → 点「深度分析」按钮 → 切到「内容生产线」看进度。

通常 1-2 分钟完成。完成后会看到：
- 4 个模型各自的洞察
- 共识观点 / 分歧观点
- 自动生成的文章草稿

### 5. 审稿 → 修订 → 发布
- 文章生成完后会自动进入「AI 审稿」流程
- 评分 ≥ 7.5 自动转入「待发布」
- 评分 < 7.5 进入「待修订」，可点「修订」让 AI 改一遍
- 满意后点「发布」→ 推送到公众号草稿箱

## 节奏建议

| 时间 | 操作 | 用时 |
|------|------|------|
| 早上 9 点 | 看概览，挑 1-2 个选题，点「深度分析」 | 2 分钟 |
| 上午 10 点 | 回来看分析结果，挑 5-8 个洞察点 | 5 分钟 |
| 上午 10:10 | 点「生成文章」 | 1 分钟（后台 5-10 分钟） |
| 中午 12 点 | 审稿结果出来了，浏览/微调 | 5 分钟 |
| 下午 2 点 | 一键发布到公众号草稿箱 | 1 分钟 |
| 下午晚些 | 公众号 App 里检查排版，定时发布 | 5 分钟 |

**总计：~20 分钟 / 篇深度文章。**

## 常用快捷操作

- `Cmd/Ctrl + R` — 刷新页面
- 「内容生产线」页可以同时跟踪 10+ 篇文章的状态
- 「批量摘要」一键给所有未生成摘要的新闻补摘要（防止逐条点）

## 遇到问题

- **「分析启动失败」** → 检查控制台里的 API key 是否填错
- **「未配置认证」** → 联系管理员设置 `DASHBOARD_AUTH_*` 环境变量
- **页面打不开 / 401** → 浏览器清缓存重输密码
- **文章一直卡在 review 不出结果** → 单条 LLM 调用偶发超时，去「内容生产线」找对应 job 点「重试」

更多问题见 [FAQ](./faq.md)。
